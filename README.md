## 1일차 — MAVLink 실습

- **왼쪽**: 코드 편집기(문법 · pyflakes 검사, 오류 줄 표시) / **MAVLink 사전**(미션에 필요한 메시지·명령·값 표와 그 밖의 메시지, 필드·타입·pymavlink 사용법, 검색과 '⭐ 미션' 필터) / **미션 체크포인트**(연결 → 이륙 → 정사각형 → 착륙 + 보너스 자동 체크) / 콘솔과 REPL
- **오른쪽**: NED 좌표계 3D 화면(드론 1~3대, LED, 지상국 ↔ 드론 신호 펄스, 충돌 표시), **통신 링크 패널**(업링크·다운링크 레인에 패킷이 흐르고, 57,600 baud 대비 사용률 표시), MAVLink 인스펙터(프레임을 바이트 단위로 색 구분)
- `print()` 출력은 콘솔과 드론 위 말풍선에 나타납니다.
- 실행 시간 제한 120초.

### 학생 코드 (pymavlink 그대로)
```python
from pymavlink import mavutil
m = connect()                         # = mavutil.mavlink_connection('udpin:0.0.0.0:14550')
m.wait_heartbeat()
m.set_mode('GUIDED')
m.mav.command_long_send(m.target_system, m.target_component,
                        mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM, 0, 1, 0, 0, 0, 0, 0, 0)
```
브라우저(Pyodide)에서는 진짜 pymavlink를 설치할 수 없어 `public/py/pymavlink/`에 **호환 모듈**을 넣었습니다. 진짜 MAVLink 2 프레임(X.25 CRC + CRC_EXTRA, 페이로드 끝의 0 잘라내기)을 만들고 해석하며, **14개 메시지 모두 실제 pymavlink와 바이트 단위로 같습니다**. 그래서 같은 코드가 실제 드론이나 SITL에서도 동작합니다.

### 가상 드론 (ArduCopter를 단순화한 동작)
| 드론이 보냄 | 드론이 받음 |
|---|---|
| HEARTBEAT 1Hz · SYS_STATUS 1Hz · ATTITUDE 10Hz · LOCAL_POSITION_NED 10Hz · GLOBAL_POSITION_INT 5Hz · VFR_HUD 4Hz · COMMAND_ACK · STATUSTEXT | SET_MODE · COMMAND_LONG · SET_POSITION_TARGET_LOCAL_NED(frame 1/7/8/9) · SET_POSITION_TARGET_GLOBAL_INT · **LED_CONTROL** · REQUEST_DATA_STREAM · HEARTBEAT |

- COMMAND_LONG: ARM/DISARM 400 · TAKEOFF 22 · LAND 21 · RTL 20 · DO_SET_MODE 176 · DO_CHANGE_SPEED 178 · CONDITION_YAW 115 · **DO_SET_RELAY 181 / DO_REPEAT_RELAY 182 (LED 켜기·반복 점멸)** · SET_MESSAGE_INTERVAL 511 · REQUEST_MESSAGE 512
- LED: `led_control_send(ts, tc, 42, 42, 3, [R,G,B]+[0]*21)` 단색, `custom_len=4` 이면 4번째 바이트가 깜빡임(Hz), `pattern=0` 끔
- 실제 기체와 비슷하게: TAKEOFF는 GUIDED + ARM에서만 · 시동 후 10초 안에 이륙하지 않으면 자동 시동 꺼짐 · 속도 명령은 3초간 새로 오지 않으면 정지 · 비행 중 DISARM 거부(강제 21196 → 추락) · 드론끼리 0.6m 안으로 가까워지면 충돌
- **잘못된 메시지 알림**: CRC 불일치 · 알 수 없는 msgid · 0xFD/0xFE가 아닌 바이트 · 없는 SYSID · 잘못된 target_component · 지원하지 않는 모드/명령/좌표계 · `z>0`(지면 아래) 같은 실수는 회색 `[sim]` 로그와 빨간 알림으로 **이유**가 나옵니다.
- 각 드론의 LOCAL_POSITION_NED 원점은 자기 출발점, 홈은 세종대(37.5503, 127.0731). 드론 2·3은 동쪽으로 3m씩 떨어져 출발합니다.

## 2일차 — 군집 경로 챌린지 (온라인 저지)

**미션: 착륙장(5 × 4, 2 m 간격)의 드론 20대로 목표 모양을 만들고 다시 착륙장으로 복귀.** 학생은 드론 20대의 **웨이포인트를 미리 계산**하는 프로그램을 씁니다. i번 드론은 착륙 지점 `starts[i]`에서 이륙해 `targets[i]`로 가고(할당 고정), 20대가 **동시에 1초 이상** 모양을 유지한 뒤 `starts[i]`로 돌아옵니다. 그동안 어떤 두 드론도 부딪히면 안 됩니다.

```text
입력 (stdin)  {"v_max": 1.0, "starts": [[x,y,z]×20], "targets": [[x,y,z]×20], "min_sep": 0.3, "tol": 0.1, "hold": 1.0}
출력 (stdout) {"paths": [ [[t,x,y,z], ...] × 20 ]}       # 단위 m, z 는 위가 +
```

| 규칙 | 값 |
|---|---|
| 착륙장 | i번 드론 착륙 지점 = (2·(i mod 5), 2·⌊i/5⌋, 0) — 모든 케이스 공통 |
| 할당 | 고정 — i번 드론 → `targets[i]` |
| 속도 | 모든 구간 속력 ≤ v_max = **1.0 m/s**. 항상 최고 속도로 갈지, 속도를 바꾸거나 기다릴지는 학생 재량 |
| 형식 | 첫 웨이포인트 t=0 · 자기 착륙 지점, t는 엄격히 증가, 드론당 웨이포인트 ≤ 20,000, 케이스당 출력 ≤ 40M자 |
| 대형 완성 | 20대 모두 자기 목표에서 **0.1 m** 이내에 **동시에 1.0 s** 이상 |
| 복귀 | 마지막 웨이포인트 = 자기 착륙 지점(0.1 m 이내). 착륙 뒤에는 제자리(충돌 검사는 계속) |
| 영역 | x −30~40 · y −30~40 · z 0~40, 미션 시간 ≤ 600 s |
| 충돌 | max(\|Δx\|,\|Δy\|,\|Δz\|) < **0.3** (정확히 0.3은 허용). 웨이포인트 사이 직선 보간, **연속 시간 전체를 해석적으로** 검사 (샘플링 아님). 충돌하면 그 케이스 실패 |
| 계산 시간 | 케이스당 30 s (넘으면 시간 초과) |
| 미션 시간 | 마지막 드론이 착륙한 시각 |
| 순위 | ① 통과한 케이스 수(많은 순 — 5개 통과는 4개 통과보다 항상 위) ② 통과한 케이스의 미션 시간 합(작은 순) ③ 먼저 낸 제출 · 학생마다 가장 좋은 제출 기준 · **2일차 공개 시각 이후 제출만** 순위에 들어감 |

**테스트 케이스** (`server/cases.js`)

| # | 이름 | 공개 | 공식 채점 | 유도하는 충돌 |
|---|---|---|---|---|
| 1 | 이륙 격자 | 공개 | – (연습용) | – |
| 2 | 원형 | 공개 | ★ | 엇갈리는 경로 |
| 3 | 글자 SJ | 공개 | – (연습용) | 수직면 정렬 |
| 4 | 구 | 공개 | ★ | 3D 교차 |
| 5 | 자리 바꾸기 | 비공개 | ★ | 착륙장을 180° 돌린 자리 상공으로 → 한가운데 정면 충돌 |
| 6 | 좁은 형상 | 비공개 | ★ | 0.45 m 간격 블록 + 뒤집힌 배치 → 근접 충돌 |
| 7 | 기둥 쌓기 | 비공개 | ★ | 한 기둥에 0.4 m 간격으로 20대 → 한 점으로 몰림 |

모든 케이스는 착륙장에서 출발해 착륙장으로 돌아옵니다. 공식 채점은 5개(공개 2 + 비공개 3)입니다. 학생에게는 공개 4개의 입력만 갑니다. 비공개 3개의 입력은 서버 밖으로 나가지 않고, 학생 화면에는 이름 대신 "비공개 1·2·3"으로 보입니다. 7개 모두 기준 풀이(고도 분리)로 풀리고, 직선 최고 속도 풀이는 1번을 빼고 모두 충돌하는 것을 확인했습니다.

**▶ 실행**: 공개 케이스 하나를 브라우저(Pyodide)에서 실행 → 즉시 채점 → 20대 3D 리플레이(타임라인, 충돌 순간 자동 정지와 빨간 상자 표시).

**✔ 제출**: 코드를 서버로 보내면 **결과 화면**(`/day2/result/?id=N`)으로 넘어가고, 서버가 채점 케이스 5개(공개 2 + 비공개 3)를 **직접 실행**해 하나씩 결과를 보여 줍니다.
- 케이스마다: 성공(미션 시간) · 충돌(드론 i·j, 시각) · 시간 초과(경로 계산 30 s 초과) · 런타임 에러 · 규칙 위반 · 계산에 걸린 시간
- 컴파일 에러는 첫 케이스에서 잡히면 나머지도 모두 컴파일 에러로 처리합니다.
- 비공개 케이스는 입력이 새지 않도록 좌표와 에러 메시지를 숨기고 요약만 보여 줍니다 (런타임 에러는 에러 종류와 줄 번호만). 관리자 화면에는 전체가 보입니다.
- 채점은 큐(`server/grader.js`)로 돌고, 동시에 `JUDGE_WORKERS`개 제출을 처리합니다. 서버가 재시작되면 채점 중이던 제출을 처음부터 다시 채점합니다.

**코드 작성**: 시작 코드는 `main.py` 하나이고, 학생은 `plan(problem)` 의 "여기에 코드를 작성하세요" 부분만 채우면 됩니다. 입력 읽기와 결과 JSON 출력은 `main()`이 이미 합니다. 예시 풀이는 직선으로 갔다가 모두 모이면 직선으로 돌아오는 방식이라 대부분 충돌합니다. 필요하면 파일과 폴더를 더 만들어 import할 수 있습니다(파일/폴더 업로드, 서버 자동 저장). 표준 라이브러리만 쓸 수 있습니다. 코드 편집기 위 **📋 규칙 · JSON 형식** 탭에 v_max 같은 제약 조건과 입출력 JSON 예시가 있습니다.

## 서버 운영 (AWS 등)

Node.js 22.13 이상 + 내장 SQLite만 씁니다. 별도 DB 서버가 필요 없습니다.

### Docker (권장)
```bash
git clone https://github.com/directorBae/drone-simulator-OJ.git && cd drone-simulator-OJ
echo "ADMIN_PASSWORD=관리자-비밀번호" > .env   # 비밀번호는 .env 에 (git 에 올라가지 않음)
docker compose up -d --build          # 80 포트 → 컨테이너 8080
```
- 데이터: `./data/droneoj.db` (학생 계정 · 코드 · 제출). 이 파일만 백업하면 됩니다.
- AWS EC2 / Lightsail: Ubuntu에 Docker 설치 → 위 명령 → 보안 그룹에서 80(또는 443) 열기.
- **학생 코드 실행 (2일차 제출)**: 컨테이너 안에서 Python 3로 실행합니다. 격리는 다음과 같습니다.
  - 권한 없는 `sandbox` 사용자로 실행하고, 환경 변수는 비웁니다.
  - 메모리(`JUDGE_MEM_MB`) · CPU 시간 · 파일 크기 · 프로세스 수를 제한합니다.
  - 서버 코드(비공개 케이스 포함)와 DB는 root만 읽을 수 있습니다.
  - 네트워크는 iptables로 막습니다. 이를 위해 `docker-compose.yml`에 `cap_add: [NET_ADMIN]`이 들어 있습니다.
  - 컨테이너 밖(Windows 등)에서 직접 실행하면 격리 없이 같은 사용자로 돌아가니 개발용으로만 쓰세요. 서버 시작 로그에 어느 쪽인지 나옵니다.
- 서버 크기: 동시에 채점하는 제출 수가 `CPU 수 − 1`(최대 4)이고, 각 채점이 학생 Python 프로세스 하나(최대 `JUDGE_MEM_MB`)와 채점 워커 하나(최대 3GB)를 씁니다. **4 vCPU · 16GB**(예: m7i.xlarge, t3.xlarge)면 제출이 몰려도 여유가 있습니다. 수업 시간에만 켜 두는 경우 인스턴스를 *중지*(종료 아님)하면 EBS의 `./data`가 그대로 남습니다. 켤 때마다 IP가 바뀌니 탄력적 IP나 도메인을 연결하세요.
- 첫 화면(`/`)에 들어오면 Python 엔진·3D·편집기 파일(압축 기준 약 6MB)을 미리 받아 두고, 1·2일차 화면은 준비가 끝날 때까지 로딩 화면을 보여 줍니다. 수업 전에 첫 화면을 한 번 열어 두게 하면 강의실 인터넷이 덜 붐빕니다.
- HTTPS: 로드밸런서(ALB)나 nginx 뒤에 두고 `COOKIE_SECURE=1`을 설정하세요. SSE(`/api/events`)를 쓰므로 nginx라면 `proxy_buffering off;`가 필요합니다.
- 브라우저는 HTTP/1.1에서 같은 서버에 연결을 6개까지만 엽니다. 실시간 알림(SSE)은 보이는 탭에서만 연결하고, 탭을 내리면 닫습니다. 그래도 강사 PC처럼 탭을 많이 띄워 두는 환경이라면 HTTPS(HTTP/2) 뒤에 두는 것이 좋습니다. HTTP/2는 연결 하나로 요청을 모두 처리합니다.

### HTTPS (운영 주소 `https://droneoj.baejeongwon.com`)
- `docker compose`는 앞단에 **Caddy**를 함께 띄웁니다(`Caddyfile`). 도메인이 서버 IP를 가리키면 Let's Encrypt 인증서를 자동으로 받아 갱신하고, HTTP는 HTTPS로 넘깁니다. 브라우저와는 HTTP/2로 통신합니다.
- DNS(GoDaddy): `droneoj` **A 레코드 → 서버의 탄력적 IP**. 레코드를 추가한 뒤 인증서가 바로 안 잡히면 `docker compose restart caddy`.
- 도메인을 바꾸려면 `.env`에 `DOMAIN=새도메인`을 넣고 `docker compose up -d`를 실행하세요.
- HTTPS로 들어온 요청에는 로그인 쿠키에 자동으로 `Secure`가 붙습니다.
- 최신 Chrome은 `http://IP` 주소를 자동으로 `https://`로 바꿔 접속하므로, 학생에게는 반드시 HTTPS 도메인을 안내하세요.

### 직접 실행
```bash
cd server && npm ci
ADMIN_PASSWORD=비밀번호 PORT=8080 npm start
```

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 8080 | |
| `ADMIN_PASSWORD` | (없으면 시작할 때 무작위로 만들어 로그에 출력) | `/uranusadmin` 로그인 |

### 관리자 페이지 (`/uranusadmin`)
- **일정·공개**: 2일차 공개 시각 · 스코어보드(예약 시각 자동 공개 / 지금 공개 / 비공개) · 제출 마감 · **1일차 해설 공개**(숨김/공개, 공개하면 1일차 예제 목록에 '📗 해설' 6개가 바로 나타남. 해설 코드는 `server/day1-solutions.js`에 있어 공개 전에는 학생이 볼 수 없음). 서버 시계 기준이고, 바뀌면 열려 있는 화면에 바로 반영됩니다.
- **학생**: 학번 · 이름 · 제출 수 · 최고 기록 / 현재 코드와 제출별 코드 보기 / **비밀번호 0000 초기화** / 계정 삭제
- **제출 현황**(실시간) · **스코어보드**(항상 보임, 학번 전체 표시) · **테스트 케이스**(비공개 포함)

### 2일차 관리자 테스트 코드
관리자로 로그인한 브라우저에서 2일차 화면을 열면 상단에 **🔧 테스트 코드** 버튼이 보입니다 (학생에게는 보이지 않고, API도 관리자만 허용). 골라서 **불러오기**(▶ 실행으로 공개 케이스 확인) 또는 **불러와서 바로 제출**(공식 채점 → 결과 화면)을 할 수 있습니다. 불러오면 그 계정의 프로젝트가 바뀝니다.

| 테스트 코드 | 예상 결과 (직접 확인함) |
|---|---|
| 전부 성공 · 빠름 — 우선순위 계획 | 5/5 · 시간 합 257.37 s |
| 전부 성공 · 느림 — 고도 분리 | 5/5 · 시간 합 411.12 s |
| 충돌 — 직선 최고 속도 (시작 코드 그대로) | 0/5 · 모두 충돌 |
| 일부 충돌 — 고도 분리, 층 간격 딱 0.3 m | 2/5 (공개만 통과) · 비공개 충돌 |
| 컴파일 에러 — for 문 콜론 빠짐 | 모두 컴파일 에러 (main.py 32번째 줄) |
| 시간 초과 — 0.0001초 간격 전수 검사 | 모두 시간 초과 (제출 하나에 케이스당 제한 시간 × 5) |
| 런타임 에러 — 입력 키 오타 | 모두 런타임 에러 (KeyError) |
| 규칙 위반 — 속도 초과 (v_max × 2) | 모두 규칙 위반 |

코드는 `server/day2-samples/<폴더>/main.py`에 시작 코드와 같은 구조(`main` + `plan`)로 있고, 목록·설명은 `server/day2-samples/index.js`에 있습니다. 고치면 서버를 다시 시작하세요.

## 알려진 제한
- ▶ 실행(공개 케이스)은 학생 브라우저의 Pyodide(Python 3.12), ✔ 제출은 서버의 CPython에서 돕니다. 표준 라이브러리만 쓰면 결과가 같습니다.
- 비공개 케이스는 결과를 요약해서 보여 주지만, 미션 시간 같은 숫자를 일부러 조작해 입력 정보를 조금씩 알아내는 것까지 막을 수는 없습니다. 의심되면 관리자 페이지에서 제출 코드를 확인하세요.
- 첫 접속 때 Pyodide(약 10MB), three.js, CodeMirror를 CDN에서 받으므로 강의실 인터넷이 필요합니다.
- `time.sleep()`은 시뮬레이션을 진행하면서 기다리느라 CPU 코어 하나를 사용합니다.
